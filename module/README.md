# Bontari Homebrew for Cyberpunk RED - Core (Unofficial)

Bontari's homebrew items for Cyberpunk RED, as Foundry VTT compendiums. This module only adds compendiums. It
does not modify the Cyberpunk RED - Core system.

## Requirements

- Foundry VTT v12
- Cyberpunk RED - Core system v0.92.4
- Recommended: [Corgo's 77 Collection](https://github.com/aky9/corgo-77-module). Several items refer to
  Corgo's items (the Neuroport, the Rebuilds, Rocklin Augmentics Skydrivers), and Corgo's Reflex Sight is
  the one Bontari's sheet uses.

## Installing

1. In Foundry's Setup screen open **Add-on Modules**, click **Install Module**, paste this into
   **Manifest URL**, and click **Install**:

       https://github.com/aky9/bontari-homebrew/releases/latest/download/module.json

   Foundry will offer updates from the same place.
2. Launch your world and enable **Bontari Homebrew** under **Manage Modules**.
3. The compendiums appear in the Compendium tab, in the **Bontari Homebrew** folder.

## What's in it

| Compendium | Contents |
|---|---|
| Bontari: Weapons | Kinetic Impact Gauntlets, Hello Cutie Kitty Bap, and the Battleboot |
| Bontari: Ammunition | HEAP and Bunker Buster rockets, Sabot ammunition |
| Bontari: Armor & Shields | The Spectre helmet and stealth suit, two TUped helmets, the Electromagnetic Shield |
| Bontari: Weapon Attachments | Flashlight Rail, Superchrome Coating, Anti-Drone Smart Scope |
| Bontari: Cyberware | Cyberware, branded cyberlimbs, and the Nachtreiher Linear Frame |
| Bontari: Sandevistans | Eleven branded Sandevistans |
| Bontari: Cyberware Enhancements | Four Self-ICE upgrades |
| Bontari: Invented Tech Upgrades | Nine Tech Upgrades, from Dual-Chip to the Rebuild overhauls |
| Bontari: Gear, Apps & Drugs | Apps, Spice, Nicotine, a poison, and the UV Flashlight |
| Bontari: Bontari Editions | Bontari's versions of existing core and Corgo's 77 items |
| Bontari: House Rules | Rule changes that aren't items: altered official items, apps, HQ upgrades |

Items that change an existing item from the core rules or from Corgo's 77 Collection carry
**(Bontari Edition)** at the end of their name, so they never clash with the item they replace. Use them
instead of the original.

Three of Bontari's entries are not built yet because the sheet doesn't give enough to build them: Shrapnel
Arrows, Grenade Arrows, and the Militech SuperFlex Steel Limbs.

Every item carries Bontari's text in full, then **Foundry notes** saying what is automated and what has to be
applied by hand.
