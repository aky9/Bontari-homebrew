# Bontari Homebrew

Bontari's homebrew items for Cyberpunk RED, built into a Foundry VTT module for the Cyberpunk RED - Core
system.

**Install in Foundry** with this manifest URL:

    https://github.com/aky9/bontari-homebrew/releases/latest/download/module.json

- `data/Bontari-Homebrew-Cyberpunk-Items.xlsx`: Bontari's sheet, the source every item is built from.
- `module/README.md`: what the module contains and how to install it.
- `docs/`: the tagged item inventory and the build plan.
- `CLAUDE.md`: how the build works, for anyone changing it.
